QUICKBITE INSTALLATION

1. Install XAMPP.
2. Start Apache and MySQL.
3. Copy the "quickbite" folder into C:\xampp\htdocs\
4. Open http://localhost/phpmyadmin
5. Import database/quickbite_db.sql
6. Open http://localhost/quickbite
